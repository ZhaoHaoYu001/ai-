# Demo 视频录制脚本

建议时长：3–4 分钟。使用声音完整讲解，并保持麦克风输入清晰。

## 0:00–0:30 产品定位

展示首页并介绍：FluentLoop 解决传统口语练习缺少真实语境、纠错打断表达、进步难以量化的问题。

## 0:30–1:00 场景与产品设计

展示四个场景和不同难度。说明每个场景都有明确训练目标，AI 会根据回答动态追问。

## 1:00–2:10 实时语音对话

进入“求职面试”：

1. 播放 Coach 开场问题。
2. 点击麦克风，用英语回答。
3. 展示转写、Coach 追问和语音播放。
4. 使用演示回答触发 `years experience` 与 `very like` 的表达纠错。

重点说明：反馈只在用户说完后出现，不会打断表达。

## 2:10–2:50 量化反馈

展示实时流利度、语法、词汇、发音分数，以及 WPM、单词数和具体改写建议。解释分数是可解释的，不只是一个黑盒数字。

## 2:50–3:30 课后报告与成长闭环

结束练习，展示四维能力报告、Coach 建议与下一步训练动作。返回首页展示成长记录。

## 3:30–4:00 技术与扩展

简述 Web Speech API 的低门槛方案、纯函数 Coach 分析引擎、文字降级能力，以及后续接入实时 LLM 和音素级发音评测的计划。
