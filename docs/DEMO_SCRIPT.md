# Demo 视频录制脚本

建议时长：3–4 分钟。使用声音完整讲解，并保持麦克风输入清晰。

## 0:00–0:30 产品定位

展示首页并介绍：FluentLoop 解决传统口语练习缺少真实语境、纠错打断表达、进步难以量化的问题。

## 0:30–1:00 场景与产品设计

展示四个场景和不同难度。说明每个场景都有明确训练目标，AI 会根据回答动态追问。

## 1:00–2:10 实时语音对话

进入“求职面试”：

1. 播放 Coach 开场问题。
2. 点击麦克风，用英语回答。
3. 展示转写、Coach 追问和语音播放。
4. 使用演示回答触发 `years experience` 与 `very like` 的表达纠错。

重点说明：反馈只在用户说完后出现，不会打断表达。

## 2:10–3:10 发音诊断与量化反馈

展示实时流利度、语法、词汇、发音分数，以及 WPM、单词数和具体改写建议。配置 Azure Speech 时，展示准确度、流利度、完整度、韵律、低分单词和 IPA 音素；同时解释未配置时的浏览器清晰度只是代理指标。

展示首字节、AI、发音评测和本轮总延迟，说明 AI 模型输出使用流式传输，但当前浏览器 STT/TTS 仍是半双工。

## 3:10–3:50 课后报告与成长闭环

结束练习，展示四维能力报告、Coach 建议与下一步训练动作。返回首页展示成长记录。

## 3:50–4:30 技术与质量

简述 Web Speech API 的低门槛方案、OpenAI Responses 流式事件、Azure Speech 发音评测、文字降级能力，以及 GitHub Actions 中的 42 项单元/集成测试和 3 项真实 Chromium E2E。
